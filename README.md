# AHNG MUSIC - Rubika Music Bot

- Entry file: `ahng_music_bot.py`
- Install: `pip install -r requirements.txt`
- Run: `python ahng_music_bot.py`
- Environment variables: `BOT_TOKEN` (required), `DB_FILE` (optional, default `ahng.db`)

Never commit the token. Set it only in the host's environment/secrets panel.
